# Source content directory

Use this directory for **future editable, verified source records** before generating public HTML. Current production records remain in `/data.js`, `/country-directory.json`, and related root files for backward compatibility.

Do not move existing production data until the page generator and all consumers are migrated together. Review official sources, record verification dates, and distinguish actual vacancies from informational listings.

The public web root remains the repository root; `/universities/`, `/subjects/`, `/opportunities/`, `/researchers/`, `/scholarships/` and `/countries/` MUST NOT move without equivalent static output.
