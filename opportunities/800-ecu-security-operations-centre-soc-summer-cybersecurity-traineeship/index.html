ECU Security Operations Centre (SOC) Summer Cybersecurity Traineeship

Eight-week intensive summer research placement working inside ECU's operational Security Operations Centre, analyzing live security event telemetry, incident response logs, and automated defense rules.

Official university details ↗Research checked, not sponsored

Application checklist & requirements

These requirements reflect published university guidelines available at the last review. Review official department guidelines before submission.

Academic degree / Prerequisites
Enrolled in third or fourth year of BSc in Cyber Security, Computer Science, or Network Engineering with minimum GPA 5.5/7.0.
English language proficiency
Strong technical English language skills.
Standardized testing (GRE/GMAT)
Not applicable.
Thesis / Research statement
Demonstrated coursework in network intrusion detection, firewall configuration, or Linux systems.
Recommendation letters
One academic referee letter.

AUD $0 application fee
