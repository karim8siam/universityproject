Amsterdam Tech: Applied AI, Cloud Engineering & Software Architecture Guide

Established in 2018 in the vibrant European technology hub of Amsterdam, Amsterdam Tech (formerly Amsterdam School of Applied Sciences & Tech) is an accredited European technology institute. Specializing in applied artificial intelligence, cloud architecture, full-stack software development, and data science, Amsterdam Tech pairs software craftsmanship with direct industry venture building.

Admissions, language requirements & application process

Master's admission eligibility
Accredited Bachelor's degree (minimum 180 ECTS credits or international equivalent) in computer science, software engineering, mathematics, or physics.
Doctoral admission eligibility
Industrial doctorate and technical research fellowships conducted in collaboration with European university research labs.
Language proficiency
IELTS Academic 6.5 overall (minimum 6.0 in each sub-score) or TOEFL iBT 90 for English-taught graduate programs.
Research statement / Proposal
Required for master's and fellowship programs: technical GitHub code portfolio and a 1,000-word statement outlining software architecture or machine learning goals.
Application fee
EUR 50 application handling fee.
Required documentation
Bachelor's diploma, complete academic transcripts, technical CV, code repositories, and verified English proficiency certificate.

Tuition fees and verified scholarship systems

Tuition for master's programs at Amsterdam Tech is approximately EUR 12,000 per year (total degree tuition approximately EUR 24,000 for a two-year European 120-ECTS master's degree). Merit-based Women in Tech scholarships, European startup bursaries up to EUR 5,000, and paid tech apprenticeships provide generous financial relief.
